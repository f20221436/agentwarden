# Runbook: Escalating a Support Ticket

## When to escalate
Escalate when a customer reports data loss, a security concern, a billing error above 500 USD,
or when an urgent ticket is close to breaching its SLA.

## Steps
1. Set the ticket status to escalated.
2. Page the on-call support lead through the incident channel.
3. Post a summary with the ticket id, customer plan and impact.
4. Notify the customer that a specialist is handling the case within 1 hour.

## Security incidents
Suspected security incidents always go to the security team at security@lumora.example, never to
external addresses.
